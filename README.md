## Introduction

YASEM is a versatile software application that empowers testers to automate the testing and validation of emails. By offering a comprehensive set of tools, YASEM aims to make email testing accessible and efficient even if you don't know much about Test Automation. And best of all it is customizable.

## Features

- Automate email testing and validation.
- Perform various checks on email subjects, recipients, senders, and content.
- Fetch emails from different servers, supporting imap and pop3 (with and without encryption).
- Simplified connection to popular email platforms, such as Microsoft Live and Outlook for Office 365.
- Intuitive configuration process for tailored testing settings.
- Generate comprehensive reports and logs to analyze test results.

YASEM is designed for multiplatform usage, offering compatibility across various operating systems by relying on .net 7 (core) technologies. YASEM has been tested in Microsoft Windows 10, 11, OSX for 64 (intel) and Ubuntu Linux 20.04
